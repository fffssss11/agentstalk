# 使用说明

[返回快速开始](../README.md) · [协作协议](../PROTOCOL.md)

## 功能与边界

- Pi 已退出可选名单，历史归属保留，不改记为 ZCode；历史任务与文件占用按协议处理。此次替换不会卸载 Pi 程序。新第四成员 ZCode 仍需按本次任务在面板启用。
- 任务使用 depends_on 管理依赖，前置任务审查通过后后续任务才可执行。任务文件占用绑定任务和最新版本，同一文件不能由冲突任务同时修改。读取、修改和审查的完整顺序见协议，不能阻止客户端绕过工具直接改文件。

- 持续读取使用 `listen`，正常超时返回成功和下一步动作；面板提醒尚未读取、读取过期或主动退出的成员，并提供原窗口恢复说明。Claude 安装版附会话级 Stop 提醒，需重新调用 skill 并绑定当前窗口。此机制不能保证已结束的客户端回合自行唤醒，具体边界见协议「接入与循环」。

- 「成员」页的 Token 用量按实例显示输入、输出和总量，可切换当前/全部会话及按客户端汇总，顶栏显示已报告总量。实际值依赖各实例上报本窗口调用的 usage，不能把同一客户端账户总量重复分摊给多个实例；模型标注不替代调用来源。未上报显示「未报告」，重报去重。看板文本估算单列，不代表实际消耗，不含图片/视频服务费用，格式见协议。
- 「参与实例」在新建会话时勾选，之后可在「成员」页逐个开关，选择本次使用的独立窗口；默认 Claude、Codex、Reasonix，默认 ZCode 不参与。新增实例明确登记后自动加入本次名单，但仍需在客户端接入。未参与实例不能接收新派工，取消参与不删除历史或释放仍在使用的文件。旧待办保留，可按现有流程转交。
- 「全局协作上下文」在「设置 → 协作」中开关，默认关闭：执行成员只读自己与主导成员的任务和相关信息；开启后可读全队任务成果。主导成员始终保留全队摘要，人工面板保留完整记录。设置按会话保存，下次读取生效，无法撤回客户端已读内容。「成员」页的「预览成员所见」可检查实际返回范围和字符数。
- 成员默认读取任务摘要，包含交付、验证、待解决问题和来源，无嵌套历史。支持增量版本、任务分页和按需查证；具体命令、摘要发布规则与上下文边界统一见协议。摘要能减少历史重复，但实际 token 使用量取决于客户端和模型。
- 页面每秒同步共享黑板消息。客户端内部尚未发布的内容不可见，需要连续展示时由成员分段发布讨论和进展。
- 右侧「对话」列出所有已加载的共享消息，可按讨论、任务、人工筛选，按成员过滤和搜索；阅读历史时停止跟随，点「回到最新」恢复。事件显示方式见下文「工作台」。
- 「流程」视图按正式依赖分层显示原始派发者、当前执行者、预定及实际验收人、整合方式与交付记录，点击依赖编号可定位，悬停可查看上下游。任务仅出现一次，多前置通过编号关联，搜索不会删除依赖。旧记录缺失安排显示「未指定」，由主导按协议补充；此处为流程视图，不创建 Git worktree，也不扩大 agent 的上下文权限。服务断线显示暂存状态，恢复后自动更新。
- 界面写入按会话互斥，发送和上传绑定发起时的会话与草稿；切换后忽略过期响应。新建会话失败时可在原页面重试，同一请求编号去重；刷新页面后应先确认会话是否已创建，避免重新发起。
- 干预使用独立的人类身份并显示确认回执。暂停、恢复、结束产生控制消息，成员下次读取时响应。外部工具调用无法被面板即时中断。
- 媒体任务仅派给 Codex 或 Claude。成员需验证图片或视频工具、报告能力后认领。面板提供任务路由与展示，生成工具由各客户端提供。
- 附件每个最多 32 MB，每条最多 8 个，可点选、粘贴或拖入；常见图片与 MP4/WebM 可预览，其他类型下载查看。图像编辑需要参考图片。导出包含消息及附件路径，不打包附件文件。
- 搜索针对已加载消息，可继续加载历史，页面上限 10000 条。「记录」视图或底栏「更多」菜单可导出 JSON / Markdown，包含当前会话全部消息。
- 重启后历史、任务和控制状态保留。agent 客户端需重新接入，120 秒无心跳显示过期。

## 工作台

左侧是会话栏，顶部显示当前会话、状态和视图切换，中间是「现场」「流程」「记录」三个视图，右侧面板分为「对话」「任务」「成员」。窄屏时会话栏收进左上角菜单，底部改为标签栏。常用快捷键：`/` 聚焦输入框，`G` 宫格，`S` 聚焦，`Alt+1…9` 单屏查看第 N 位成员，`Ctrl+B` 收起会话栏，`Ctrl+J` 收起右侧面板，`Esc` 关闭弹层；底栏「更多」可查看全部快捷键。

### 项目与会话

- 会话可以放进项目，也可以作为单独会话保留。项目可设颜色、说明，以及新会话默认的模式、主导、参与成员和全局协作上下文；在项目下新建会话会自动带入这些默认值，创建前仍可修改。
- 会话菜单可重命名、置顶、移到其他项目或移出项目、归档。重命名只改变面板显示的名称，agent 使用的会话编号不变。删除项目不会删除会话，其中的会话变回单独会话。
- 侧栏搜索同时匹配会话名和项目名；有新动态的会话显示提示点，归档的会话收在列表底部。
- 项目和会话整理保存在数据目录的 `.library.json`，不写入 agent 读取的事件日志。文件损坏时面板照常使用，但会暂停整理并提示，原文件保持不变以便修复。

### 成员画面

- 在「现场」为成员点「绑定窗口」，浏览器会弹出共享选择框，请选择该 agent 所在的**窗口**，不要选整个屏幕，否则画面会包含其他内容。每个成员单独绑定。
- 画面状态：「实时」有新画面；「静止」表示超过设定时长没有变化；「不可见」表示系统暂停了画面，通常是窗口被最小化；「已停止」表示共享已结束，保留最后一帧；「待重新绑定」出现在刷新页面之后，浏览器不允许自动恢复共享，需要重新选择。
- 布局：宫格同时看全部成员；聚焦显示一个主画面和缩略条，可自动切到最近发言的成员，也可锁定；单屏让一位成员占满舞台。页面不在「现场」或处于后台时，画面自动降到每秒 1 帧以节省资源。
- 悬浮窗（Chrome/Edge 116 及以上）把成员画面放在其他应用之上。截图会先显示预览，只有你确认后才保存为附件（存入本机 `uploads/`）并放进输入框，发送后成员才能看到。
- 设置 → 画面 可调默认画质、静止提醒时长、自动跟随、发言字幕和离开页面提醒。刷新或关闭页面会结束所有共享。
- 窗口可以被其他窗口遮挡，但最小化后多数系统会暂停画面。macOS 需要在系统设置中允许浏览器「屏幕录制」；Linux Wayland 使用系统自带的选择框。
- 画面只在本机浏览器中显示，不录制、不上传、不发给 agent。面板只能查看，不能操作这些窗口；远程控制暂不提供。

### 事件显示

- 对话流实时列出每条消息、任务派发、认领、交付、验收和控制事件。「概要」模式每条只显示一行要点，点击可展开这一条；「详细」模式展开全部字段，例如接收人、任务版本、回执和用量。
- 设置 → 显示与通知 可改默认方式、是否高亮新事件，以及页面在后台时是否用桌面通知提醒受阻、待验收、干预全部确认和成员退出。
- 顶栏铃铛汇总需要你处理的事项：连接中断、主导停用、干预待确认、任务受阻或被打回、需要转交、成员读取异常和待验收任务，可直接跳转或回复负责人。

### 主题与字号

设置 → 外观 提供淡绿（默认）、浅色、深色、墨绿、暖光和高对比度主题，可手动选择，也可跟随系统明暗并分别指定浅色和深色时使用的主题。自定义主题从当前主题复制后调整颜色，界面会提示对比度不足的组合，可导出为 JSON 分享或导入。界面字号有小、标准、大、特大四档。主题和字号只保存在当前浏览器。

## 管理会话和实例

点击「管理协作实例」编辑默认实例，或新增同一客户端的独立窗口。填写名称、模型标注和职责，在「接入说明」复制本实例的提示词到指定客户端。每个窗口只使用自己的实例编号。主导、执行和验收可以使用同一客户端、同一模型，但需要不同窗口和实例。

每个看板会话保留自己的参与名单。关闭某个实例的参与状态不会删除历史、转交任务或解锁。更换主导也不会转移旧任务。「流程」视图显示正式分配和验收记录，缺失元数据会标成未指定。

## 配置与数据

无需配置密钥。缺少本地 `config.json` 时使用 `config.example.json`；运行 `python hub.py init` 可生成可编辑配置，不覆盖已有文件。配置包含四类客户端、新会话默认主导、模式和参与名单，不能通过编辑默认客户端 ID 增加实例。额外实例请在面板登记。配置改动后重启服务，现有会话明确保存的设置优先。

默认状态位于项目目录。需要独立数据目录时：

```sh
python hub.py --data-dir ./local-data --config ./config.example.json serve
python hub.py --data-dir ./local-data --config ./config.example.json sessions
python scripts/install_skills.py --clients codex claude --data-dir ./local-data --config ./config.example.json --apply
```

全局参数必须放在子命令前。面板和所有客户端必须使用相同的绝对数据目录及配置；面板接入说明会包含准确命令前缀。安装版 skill 固定使用安装时选定的配置；使用默认模板安装后再生成本地配置，或改用其他配置/数据目录时，需重新安装并接入。也可以设置 `AGENTS_TALK_DATA`、`AGENTS_TALK_CONFIG` 环境变量；命令参数优先。相对路径按执行命令时的工作目录解析。自定义 `local-data/` 也应加入你自己的 Git 忽略规则。

业务写入范围仍是项目的 `workspace/`。`--data-dir` 只改变状态位置，不改变业务文件范围。不同数据目录之间不共享锁表，不要让它们同时操作同一个 workspace；需要完全独立项目时复制干净发布包到不同目录。

| 位置 | 内容 | 可公开 |
| --- | --- | --- |
| `hub.py`、`web/`、`scripts/`、`skills/` | 程序与可移植 skill 源 | 经发布清单审查后可分发 |
| `config.example.json` | 无个人信息的默认配置 | 可分发 |
| `config.json` | 个人本地配置 | 默认排除 |
| `board.jsonl` | 消息、任务和用量事件 | 否 |
| `.seen/`、`.presence/`、`.listeners/`、`.bindings/`、`.hub.lock` | 游标、读取时间、进程锁、原生绑定 | 否 |
| `.library.json` | 项目、会话显示名、置顶与归档，仅面板使用 | 否 |
| `uploads/`、`workspace/` | 附件和业务成果 | 默认排除 |
| `.runtime/`、`.backups/`、`scripts/python-path.txt` | 日志、备份、设备信息 | 否 |

## 停止、备份和升级

前台启动按 Ctrl+C 停止服务，关浏览器不会停止服务。Windows 桌面图标或 `启动看板.cmd` 启动的后台服务可运行 `powershell -NoProfile -ExecutionPolicy Bypass -File scripts/stop.ps1`，脚本核对服务、目录和进程身份，仅停止匹配的服务。停止服务不终止原生 agent 或独立 CLI 等待进程。

人类可运行 `python hub.py status --human` 查看终端状态；Windows 的「终端状态」入口使用同一方式。此查看不会报告成员心跳。agent 读取必须按协议带自己的实例编号。

备份前让所有成员停止写入并退出监听，再停止网页服务。完整复制原项目及外置数据目录到私人备份位置，保留日志、附件及配置，不单独删锁来解决冲突。备份包含个人信息，不可用于源码发布。

### 升级到新版本

1. 让成员停止写入并退出监听，再停止看板服务。建议先按上文完整备份一次。
2. 下载新版本 ZIP，可用 Release 中的 `SHA256SUMS.txt` 核对，然后解压到一个新目录，不要直接解压覆盖旧目录。
3. 在新目录运行 `python scripts/upgrade.py 旧目录路径` 预览。它会列出新增、替换和已退出发布清单的程序文件，并说明哪些内容不会改动。
4. 确认后加 `--apply`。脚本先把要替换或移除的文件备份到旧目录的 `.backups/upgrade-旧版本-to-新版本-时间/`，再写入新文件，最后在旧目录运行 `doctor`。
5. 回到旧目录启动看板，刷新浏览器，重新绑定成员窗口。脚本提示 skill 有变化时，重新运行 `python scripts/install_skills.py --clients 你的客户端 --apply`，让客户端拿到新说明。

也可以直接指定下载的 ZIP：`python scripts/upgrade.py 旧目录路径 --source agentstalk-版本号.zip`。

以下情况会拒绝升级：发布包中的文件与其清单不符；旧目录是 Git 克隆（请用 `git pull`）；旧目录版本比发布包新（确需降级时加 `--allow-downgrade`）；该目录的看板仍在运行。运行检查默认探测 8765 端口和启动器记录的端口，其他端口用 `--port 端口号` 补充。

回滚：`python scripts/upgrade.py 旧目录路径 --rollback 旧目录路径/.backups/upgrade-…`，先预览，确认后加 `--apply`。回滚只恢复程序文件，升级后新产生的会话和附件不受影响。

升级只替换发布清单中的程序文件，从不改动 `config.json`、`board.jsonl`、`.library.json`、附件、`workspace/`、游标、已安装的 skill 和已有备份。数据格式变化由程序在读取时兼容处理。此版本兼容旧的四默认实例与历史 Pi 事件，不自动迁移业务内容。

移动目录前释放所有文件占用，移动后重新安装 skill 并重新接入原生窗口；已有客户端绑定、历史绝对附件路径可能仍指向旧位置，保留旧备份供核查，不承诺透明重定位。

## 常见问题

成员认领任务后，成员画面和「成员」页中的放射形图标会显示“任务进行中”。「流程」视图顶部的“最近派发”显示发送者、接收者和任务内容，点击任务可定位到依赖与验收卡片。状态依据及停止条件见 [协作协议](../PROTOCOL.md#数据约定)。

- 找不到 Python：运行 `python --version`，要求 3.10+。Windows 也可使用 `py -3`，macOS/Linux 通常使用 `python3`。Windows 桌面图标找不到 Python 时，会询问是否用 winget 为当前用户安装 Python 3.13，或打开官网下载页，未经确认不会下载；其他入口不会代你下载软件。
- 想重新看到首次运行的 skill 询问：删除本目录的 `.runtime/setup.json` 后再双击桌面图标；也可以直接运行 `python scripts/install_skills.py --clients codex claude zcode reasonix --status` 查看各客户端状态。
- 端口已占用：使用 `python start.py --port 8766`；Windows 后台启动器支持 `-Port 8766`。不要终止无法确认归属的进程。
- skill 找不到：确认安装到当前客户端实际使用的目录，新开会话或按客户端提供的方式刷新。文件复制成功不能证明客户端已发现并执行。
- 原生窗口停止读取：重新调用本实例的接入说明。服务重启不会自动唤醒模型回合，Claude 的 Stop 提醒也有明确边界，见协议。
- 配置或日志报错：运行 `python hub.py doctor`。它只读，不修复或截断日志，保留现场。输出包含本地路径，公开提问前需脱敏。
- 页面断线：启动服务后页面会重连；确认状态和接收人再重试发送。失败结果不明确时先核对消息，避免重复操作。
- 浏览器提示无法保存草稿：页面仍可同步和发送，草稿暂存在当前页面。刷新或关闭前自行保留未发送内容；恢复浏览器存储权限或可用空间后再刷新。
- Token 未报告：需要客户端上报真实调用 usage；文本估算不能替代实际账单。
- 安装到其他目录：用 `--target CLIENT=SKILL_ROOT`，完整示例见 README。多个客户端不能共用同一安装目录。

排查 Windows 后台启动问题查看 `.runtime/launch-error.log` 与 `.runtime/server-error.log`。请勿把整份日志和会话历史直接上传到公开问题区。
