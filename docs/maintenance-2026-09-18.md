# Agents Talk 维护问题与验证报告

日期：2026-09-18。范围为 Agents Talk 程序、测试、安装发布工具和相关文档。此报告记录本地未发布维护修改，版本号仍为 `0.1.0-rc.3`，已有 Release 附件不代表这些改动。

## 维护判断

现有协作流程已有任务依赖、文件占用、人工控制和独立验收机制。本轮优先修复可能导致记录不可读、操作误发、状态串目录和发布隐私检查失效的问题。保留 Python 标准库后端及本地静态前端，避免同时引入新的运行依赖和数据迁移。

原有 93 项 Python 测试中 92 项通过、1 项因本机符号链接权限跳过。补充异常输入、故障注入和隔离浏览器测试后，确认原覆盖仍有遗漏。以下结论来自可定位代码、隔离复现或专项测试；优先级是本轮维护判断。

## 性能测量

同一 Windows / Python 3.13.5 环境，基线来自维护前源码快照。每组预热 1 次，计时 5 次，表格为中位数。数据是隔离目录内的合成文本消息，测量 `read_state` 进程内调用，包含日志读取及状态推导，不含 HTTP、浏览器渲染或模型调用。

| 消息数与正文 | 修改前 | 修改后 | 耗时下降 |
| --- | ---: | ---: | ---: |
| 1,000 条，每条 250 个 ASCII 字符 | 96.93 ms | 15.75 ms | 83.8% |
| 10,000 条，每条 250 个 ASCII 字符 | 906.11 ms | 148.24 ms | 83.6% |
| 1,000 条，每条 240 个中英文混合字符 | 119.61 ms | 24.41 ms | 79.6% |
| 10,000 条，每条 240 个中英文混合字符 | 1,187.68 ms | 240.94 ms | 79.7% |

此结果仅说明上述文本历史场景的读取改善。包含大量任务、附件和多会话的实际性能仍需单独测量。中间基准记录曾把 ASCII 正文长度固定标成 240；最终脚本已按实际长度输出为 250，表格采用最终记录。

## 实际验证

- 本机环境：Windows、Python 3.13.5、Node 24.18.0、npm 11.16.0、项目锁定的 Playwright Chromium。
- `npm ci` 与 `npx playwright install chromium` 成功，未使用私有依赖路径或关闭 TLS 检查。
- 修改后 Python 集成测试：109 项，108 通过、1 项符号链接权限跳过，用时 82.225 秒。
- 第一轮干净副本：109 项 Python 测试，108 通过、1 项权限跳过，用时 94.698 秒；重新安装 npm 依赖后四组浏览器回归与 5 项辅助函数测试通过。随后附件重试修复增加 1 项回归。
- 最终干净副本：110 项 Python 测试，109 通过、1 项权限跳过，用时 67.497 秒；附件改动后重新执行 browser 全部竞态与真实 HTTP/上传/重连测试，通过。人类终端脚本的隔离单次运行通过，确认未刷新成员心跳。
- 两轮 `npm test` 均通过，每轮包含 5 项辅助函数测试及 browser、observatory、instances、activity 四组浏览器脚本。
- 浏览器验证覆盖发送、上传、人工干预回执、暂停/恢复/结束、会话切换竞态、幂等重试、断线重连、上下文范围、实例管理、独立验收、任务依赖、用量、活动动画和减少动态效果。
- 已查看桌面、390px 窄屏与存储故障截图；自动化同时覆盖窄屏横向无溢出和横屏观察窗。
- `npm run check`、发布精确清单检查、源码静态隐私审计通过。独立差异审查覆盖前端存储降级、跨会话草稿清理、测试服务隔离和文本估算等价性。

## 仍需验证的范围

- 本轮未运行 macOS/Linux、Python 3.10 的实际环境；已有 CI 配置不能替代本次执行结果。
- 未人工测试 Firefox、Safari、真实系统输入法和屏幕阅读器；输入法及存储异常采用受控事件和异常注入。
- 未验证真实客户端的模型/API 调用、skill 发现或媒体生成。界面与协议通过不能证明外部客户端已经接入。
- 符号链接拒绝用例受本机权限限制跳过，需在支持创建符号链接的环境执行。
- 源码隐私扫描属于模式检查，无法证明所有未知格式、图像内容和任意凭证均安全。本轮没有第三方安全审计。
- 长历史仍会重建状态，超大日志、长期稳定运行和磁盘硬件故障尚未建立完整压力基准。
- CLI 在提交前保存附件，失败或重试可能留下未被消息引用的文件，目前没有自动回收流程。自动清理需识别仍在进行的上传，不能直接删除所有暂未引用的附件。

后续路线优先补齐上述跨平台和真实客户端验证，并根据实际长会话测量决定是否增加索引或状态快照。现有数据模型未迁移，程序更新后的后端逻辑在服务重启时加载。
